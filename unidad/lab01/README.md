# Laboratorio N° 01: Entorno Web, HTTP y HTML Semántico

## Objetivos
- Configurar y validar el entorno de desarrollo web profesional (VS Code, Extensiones, Node.js y Git).
- Inspeccionar y analizar la estructura de transacciones HTTP (peticiones GET, cabeceras, cuerpo y códigos de estado) mediante Chrome DevTools.
- Construir una interfaz web estática accesible y semántica utilizando elementos de HTML5.
